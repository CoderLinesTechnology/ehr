## Decisions
* **Figures** (the comp's numbers are not derivable from its six cards, so the definitions are ours): *Total Programs* = open programs (upcoming, active, on hold); *Total Participants* = live **active** enrollments (demo never counts; flagged substance-use programs count only for members with `programs.view_sud`); *Upcoming Starts* = non-cancelled sessions starting within the next 7 days (the fixture's three schedule items); *Completed* = live completed enrollments (the fixture seeds four).
* The cards show the program's **first active level** (by order) as its tag; participant counts are live active enrollments; a flagged program shows "Restricted" instead of a number to members without `programs.view_sud`.
* Everything unmeasured (detail, forms, participant, session pages) uses the same tokens in `.pr-panel` boxes and the shared components.
